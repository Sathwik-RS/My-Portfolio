# MERN Portfolio
1. Edit `client/src/config.js` (name, GitHub + LeetCode usernames, links).
2. Server: `cd server && cp .env.example .env && npm i && npm run seed && npm run dev`  (MongoDB local or Atlas)
3. Client: `cd client && npm i && npm run dev`  → http://localhost:5173
No MongoDB yet? The site still works: it falls back to `client/src/data.js`.
Edit your projects/certs/hobbies in `server/seed.js` (re-run `npm run seed`) or in `data.js`.
